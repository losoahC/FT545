## 输入输出约定

下表中 n 是观测数，p 是变量数。矩阵函数接收二维数值列表或 NumPy 数组，
输出 NumPy 数组；拟合函数接收一维数值样本，输出参数字典。

| 部分 | 输入 | 输出与边界约定 |
| --- | --- | --- |
| 1.1–1.4 | n×p 数据，p≥1，允许 NaN | p×p 矩阵；有效观测不足两条时为 NaN；常数列相关系数为 NaN、协方差为 0 |
| 2.1–2.3 | n×p 有限数据，n≥2、p≥1，0<decay<1 | p×p 矩阵；最后一行最新，权重最大；常数列相关系数为 NaN、协方差为 0 |
| 3.1–3.4 | 有限对称方阵，对角线严格为正 | 同形状修正矩阵，保留原方差；Higham 的容差在相关系数尺度上判断 |
| 4.1 | 有限对称 PSD 方阵 | 同形状下三角 L，L @ L.T 重建输入，允许零方差及奇异矩阵 |
| 5.1–5.4 | 模拟次数≥2、协方差方阵，可选修正函数和 seed | n_samples×p 零均值正态样本；未指定修正函数时拒绝明显非 PSD 输入 |
| 5.5 | PSD 方阵、模拟次数≥2、0<explained≤1 | n_samples×p 样本；保留累计方差达到阈值的最少主成分，输出仍有 p 列 |
| 6.1–6.2 | pandas DataFrame，≥2 行，唯一列名，日期列及正的有限价格 | n−1 行 DataFrame，保留原列顺序和结束日期，重置行索引；按输入行序计算，不自动排序 |
| 7.1 | 至少 2 个有限且非恒定的样本 | mu、sigma；sigma 是 ddof=1 的样本标准差 |
| 7.2 | 至少 4 个有限且非恒定的样本 | mu、sigma、nu；sigma 是 t 分布尺度，不是标准差 |
| 7.3 | n×p 自变量、不含截距列；长度 n 的因变量 | mu=0、sigma、nu、Alpha、B1…Bp；要求设计矩阵满秩、n>p+3，拒绝完美拟合 |
| 7.4 | 总对数似然、样本数 n、参数数 k；n>k+1、k≥1 | AICc 标量；7.2 的参数数为 3 |
| 7.5 | 至少 4 个有限非恒定样本，样本矩允许有限 NIG 解 | mu、alpha、beta、delta；无可行矩估计时抛出 ValueError |
| 7.6 | 至少 4 个有限非恒定样本 | mu、alpha、beta、delta；由 SciPy 参数转换而来 |

## 本次发现并修复

- 非零小数常数列（例如 0.1）此前可能产生极小的非零方差：普通/EW
  协方差现在先平移再中心化；拟合函数直接检查样本是否恒定。
- 收益率函数现在明确拒绝非 DataFrame、重复列名及非字符串 method。
- 对数收益率改为两个对数相减，避免价格比值先溢出；无法表示的算术收益率
  明确报错，不返回无穷值。
- t 分布拟合增加返回参数合法性检查。

## 验证范围和精度

- 标准案例全部通过。第 5 部分是随机模拟，按抽样误差比较，不能要求与
  Julia 的随机结果逐元素完全相同。第 7 部分数值优化使用各案例注明的容差。
- 用 pandas 独立复核四种缺失值计算，用 NumPy 加权协方差复核 EW 计算。
- 检查随机不定矩阵修正后的对称性、对角线和特征值，以及低秩矩阵 Cholesky 重建。
- 检查单变量、零方差模拟、日期类型、非默认索引、输出形状、输入不被修改。
- 检查 t 拟合的平移缩放关系、回归因变量平移关系、NIG 矩还原及平移缩放关系。
- Higham 的结果允许容差范围内的微小负特征值；矩阵修正函数目前不接收
  零对角线输入。分布优化不保证任意数据集都存在唯一有限最优解。

这些检查覆盖当前约定、标准数据和新增边界案例，不代表对所有可能的输入作出数学保证。
